Helmet Detection System

A real-time helmet detection system developed using Python, OpenCV, and YOLO for enhancing road safety and traffic monitoring.

 Features

- Real-time helmet detection
- Webcam/live video support
- Detects riders with and without helmets
- Object detection using YOLO
- Image and video input support

 Technologies Used

- Python
- OpenCV
- YOLO
- NumPy
- Computer Vision

 Workflow

1. Collect dataset
2. Train YOLO model
3. Process video/webcam frames
4. Detect helmets in real-time
5. Display detection results
